## §4 关键发现

### 4.1 Agent 上下文偏移（严重）

Agent 在 Round 3 和 Round 11 两次将模块理解从 `hybrid_controller`（多协议总线桥接器）偏移到 `bubble_squeeze`（多通道交织挤气泡模块）。原因可能是：
- Agent 内部上下文窗口溢出，丢失了早期对话
- 模板或默认场景覆盖了实际输入

**影响**：用户需主动纠正，浪费 2 轮对话。

### 4.2 信息遗落（中等）

Agent 在 Round 5 遗忘了用户在 Round 2 已确认的 14nm/400MHz，再次询问。

**影响**：用户体验差，效率降低。

### 4.3 文件路由错误（中等）

Agent 在 Round 11 将文件写入 `bubble_squeeze_work/` 而非调试输出目录。

**影响**：调试输出目录的文件是早期版本，最终版本在错误目录。

### 4.4 SRAM 约束违反（已修复）

Agent 初始方案 SRAM 4KB 超出 2KB 硬约束，需用户指出后调整。

**影响**：说明 Agent 在方案设计时未严格检查硬约束。

### 4.5 用户扮演了 devils-advocate 角色

challenging_reviewer 角色自然地扮演了对抗性评审，提出了高质量的技术质疑。

**正面**：验证了 Agent 在面对挑战性问题时的应变能力。
