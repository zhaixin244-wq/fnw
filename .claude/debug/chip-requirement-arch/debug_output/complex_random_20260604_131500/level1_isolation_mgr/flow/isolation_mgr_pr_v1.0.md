## 父模块上下文摘要

**功能**：FPGA 部分重配置控制器，支持多租户隔离和比特流完整性校验。

**关键约束**：16nm / 500MHz / 逻辑 < 200kGates / 动态功耗 < 180mW

**核心隔离需求**：逻辑隔离为主（地址空间+访问控制），关键配置寄存器物理隔离

**兄弟模块**：
- bitstream_rx_engine：接收比特流，需受隔离管理控制
- bitstream_val_mgr：校验比特流，校验失败触发回滚
- icap_write_engine：写入 ICAP，需受隔离管理控制
- reg_interface：APB 寄存器接口，提供隔离状态查询
