# 软件-硬件协同方法论（共享）

> 本模板定义芯片设计中硬件与软件协同验证、协同设计的方法论。
> 供硬件 Agent（chip-code-writer、chip-fs-writer 等）和软件 Agent（chip-sw-driver、chip-firmware-writer 等）共同引用。

---

## 1. 软硬件协同模型

```
需求分析（软硬件联合）
    │
    ├─→ 硬件设计                    ├─→ 软件设计
    │   ├─ FS 功能规格              │   ├─ 驱动架构
    │   ├─ UA 微架构                │   ├─ API 接口
    │   ├─ RTL 实现                │   ├─ 寄存器头文件
    │   └─ 验证环境                │   └─ 固件代码
    │                               │
    └──────────── 接口对齐 ─────────┘
                    │
                    ├─→ 协同验证
                    │   ├─ 硬件仿真 + 软件驱动
                    │   ├─ 寄存器读写验证
                    │   ├─ 中断处理验证
                    │   └─ 性能协同分析
                    │
                    └─→ 签核
```

## 2. 协同设计阶段

### 2.1 需求阶段协同

| 活动 | 硬件 Agent | 软件 Agent | 协同点 |
|------|-----------|-----------|--------|
| 功能需求 | `chip-fs-writer` FS §4 | `chip-sw-driver` 需求分析 | 功能边界划分 |
| 接口需求 | `chip-fs-writer` §6 | `chip-sw-driver` API 设计 | 接口协议对齐 |
| 寄存器需求 | `chip-fs-writer` §7 | `chip-sw-driver` 寄存器映射 | 寄存器定义确认 |
| 性能需求 | `chip-fs-writer` §8 | `chip-sw-profiler` 性能目标 | PPA 指标对齐 |

**协同输出**：软硬件接口协议文档（由 `chip-sw-driver` 产出）

### 2.2 设计阶段协同

| 活动 | 硬件 Agent | 软件 Agent | 协同点 |
|------|-----------|-----------|--------|
| 寄存器设计 | `chip-microarch-writer` §5.6 | `chip-sw-driver` 寄存器映射 | 寄存器布局确认 |
| 中断设计 | `chip-microarch-writer` §5.2 | `chip-sw-driver` 中断处理 | 中断向量对齐 |
| DMA 设计 | `chip-microarch-writer` §5.1 | `chip-sw-driver` DMA 驱动 | 描述符格式对齐 |
| 错误处理 | `chip-microarch-writer` §5.2 | `chip-sw-driver` 错误恢复 | 错误码对齐 |

### 2.3 实现阶段协同

| 活动 | 硬件 Agent | 软件 Agent | 协同点 |
|------|-----------|-----------|--------|
| RTL 编码 | `chip-code-writer` | - | 寄存器头文件生成 |
| 驱动编码 | - | `chip-firmware-writer` | 寄存器头文件消费 |
| 头文件同步 | `chip-code-writer` 生成 .svh | `chip-firmware-writer` 消费 .h | 格式转换 |
| 验证环境 | `chip-env-writer` | `chip-sw-verifier` | Mock 硬件层 |

## 3. 接口对齐规范

### 3.1 寄存器接口对齐

**铁律：寄存器定义以 FS §7 为唯一真相源，硬件和软件必须同步。**

| 对齐项 | 硬件定义 | 软件消费 | 同步方式 |
|--------|----------|----------|----------|
| 寄存器地址 | FS §7.1 地址映射表 | .h 头文件地址宏 | 自动生成 |
| 位域定义 | FS §7.2 位域定义 | .h 头文件位域宏 | 自动生成 |
| 访问类型 | RW/RO/W1C/WO | 驱动读写函数 | 约束检查 |
| 复位值 | FS §7.2 复位值 | 驱动初始化序列 | 验证检查 |

**寄存器头文件生成流程**：
```
FS §7 寄存器定义 → chip-code-writer 生成 .svh → 脚本转换为 .h → chip-firmware-writer 消费
```

### 3.2 中断接口对齐

| 对齐项 | 硬件定义 | 软件消费 | 同步方式 |
|--------|----------|----------|----------|
| 中断信号 | FS §6 中断端口 | 驱动中断处理函数 | 接口文档 |
| 中断状态 | FS §7 INT_STATUS 寄存器 | 驱动状态读取 | 寄存器头文件 |
| 中断清除 | FS §7 INT_CLEAR 寄存器 | 驱动清除操作 | 寄存器头文件 |
| 中断掩码 | FS §7 INT_MASK 寄存器 | 驱动掩码配置 | 寄存器头文件 |

### 3.3 DMA 接口对齐

| 对齐项 | 硬件定义 | 软件消费 | 同步方式 |
|--------|----------|----------|----------|
| 描述符格式 | UA §5.1 数据通路 | 驱动描述符构建 | 接口文档 |
| 描述符地址 | 寄存器 DESC_ADDR | 驱动地址配置 | 寄存器头文件 |
| 传输状态 | 寄存器 XFER_STATUS | 驱动状态查询 | 寄存器头文件 |
| 错误码 | 寄存器 ERROR_CODE | 驱动错误处理 | 寄存器头文件 |

## 4. 协同验证策略

### 4.1 协同验证层次

| 层次 | 验证内容 | 硬件环境 | 软件环境 | 验证目标 |
|------|----------|----------|----------|----------|
| L1: 寄存器读写 | 寄存器访问正确性 | RTL 仿真 | 驱动代码 | 100% 寄存器覆盖 |
| L2: 功能协同 | 硬件功能 + 软件控制 | RTL 仿真 | 驱动代码 | 核心功能验证 |
| L3: 中断处理 | 中断触发 + 软件响应 | RTL 仿真 | 驱动代码 | 中断链路验证 |
| L4: 性能协同 | 硬件性能 + 软件效率 | RTL 仿真 | 驱动代码 | 性能指标验证 |

### 4.2 协同验证用例

| 用例类型 | 描述 | 硬件检查点 | 软件检查点 |
|----------|------|-----------|-----------|
| 寄存器读写 | 驱动读写所有寄存器 | 值正确 | 返回值正确 |
| 功能控制 | 驱动配置硬件功能 | 功能生效 | 状态正确 |
| 中断处理 | 硬件触发中断 | 中断信号 | 驱动响应 |
| 错误恢复 | 硬件报错 + 软件恢复 | 错误码 | 恢复成功 |
| 性能测试 | 驱动持续传输 | 吞吐达标 | 延迟达标 |

### 4.3 Mock 硬件层

**铁律：软件验证必须有 Mock 硬件层，禁止直接操作真实硬件。**

| Mock 层级 | 实现方式 | 适用场景 |
|-----------|----------|----------|
| 寄存器 Mock | 内存映射模拟寄存器 | 单元测试 |
| 接口 Mock | 模拟硬件接口行为 | 集成测试 |
| 时序 Mock | 模拟硬件时序延迟 | 性能测试 |

**Mock 接口定义**：
```c
// Mock 硬件层接口
typedef struct {
    uint32_t (*reg_read)(uint32_t addr);
    void (*reg_write)(uint32_t addr, uint32_t data);
    int (*wait_interrupt)(uint32_t timeout_ms);
    uint32_t (*get_status)(void);
} hw_mock_ops_t;
```

## 6. 各 Agent 协同职责

### 6.1 硬件 Agent 职责

| Agent | 协同职责 | 输出物 |

## 7. 协同问题处理

### 7.1 接口不一致处理

```
发现不一致 → 判定真相源（FS > UA > RTL > 驱动）→ 修正下游 → 验证一致性
```

| 不一致类型 | 真相源 | 修正方 |
|-----------|--------|--------|
| 寄存器地址 | FS §7 | 修正驱动代码 |
| 位域定义 | FS §7 | 修正驱动代码 |
| 中断信号 | FS §6 | 修正驱动代码 |
| 接口协议 | FS §6 | 修正 RTL 或驱动 |

### 7.2 性能问题处理

```
性能不达标 → 定位瓶颈（硬件/软件）→ 优化 → 重新验证
```

| 瓶颈类型 | 优化方向 | 负责 Agent |
|----------|----------|-----------|
| 硬件延迟 | RTL 优化 / 流水线调整 | `chip-code-writer` |
| 软件开销 | 驱动优化 / 中断合并 | `chip-firmware-writer` |
| 接口效率 | DMA 优化 / 批量传输 | `chip-sw-driver` |
| 总线带宽 | 总线仲裁优化 | `chip-microarch-writer` |
