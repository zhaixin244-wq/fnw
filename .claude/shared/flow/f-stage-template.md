## 6. 执行说明

### 6.1 F 阶段执行步骤

1. 收集所有子模块的方案文档
2. 检查子模块间接口一致性（信号名/位宽/方向/握手协议）
3. 生成模块连接拓扑图
4. 输出顶层方案文档（§14）

### 6.2 与 chip-top-integrator 的职责边界

| 工作项 | chip-requirement-arch（本阶段） | chip-top-integrator（RTL 阶段） |
|--------|-------------------------------|-------------------------------|
| 接口一致性检查 | ✅ 方案层面检查（信号名/位宽/方向） | ✅ RTL 层面检查（实际端口映射） |
| 内部连线定义 | ✅ 方案规划（信号列表+映射关系） | ✅ RTL 实现（assign + 实例化） |
| 顶层模块代码 | ❌ 不生成 | ✅ 生成+Lint |
| 系统级 Lint | ❌ 不执行 | ✅ Verilator/SpyGlass |
| 拓扑图 | ✅ 方案层面（D2 架构图） | ✅ RTL 层面（实际连线图） |
