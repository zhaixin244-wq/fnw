# Wiki Save — 会话归档

将当前会话的关键信息归档到 wiki 系统。

## 执行流程

1. **提取会话摘要**：回顾本次会话的：
   - 讨论的知识点
   - 做出的设计决策
   - 生成/修改的文档
   - 发现的问题和解决方案

2. **更新 Hot Cache**：刷新 `wiki/hot.md` 中的：
   - 当前工作上下文
   - 最近修改的页面
   - 会话记忆摘要

3. **创建新页面（如需）**：如果会话中产生了新的知识点：
   - 生成结构化 wiki 页面
   - 添加到对应目录（entities/concepts/comparisons）
   - 更新交叉引用

4. **更新索引**：更新 `wiki/index.md`

## 参数

- `$ARGUMENTS` — 可选，指定归档标题

## 使用示例

```
/wiki-save                              # 自动归档
/wiki-save "PCIe Gen6 FEC 机制分析"      # 指定标题
```
